# Assets

Os recursos visuais e sonoros do Fronteira Web ficarão organizados aqui conforme forem sendo produzidos.

Estrutura planejada:

```text
assets/
  sprites/
    units/
    structures/
    effects/
  tiles/
  ui/
  audio/
    music/
    sfx/
  fonts/
```

Enquanto o protótipo V0.1 valida escala, campo e lógica, os elementos são desenhados diretamente no Canvas. Assim que a direção visual estiver aprovada, eles serão substituídos por sprites 16-bit sem alterar o motor da batalha.
